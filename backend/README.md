# SentinelAI Backend

This directory will contain the FastAPI backend service responsible for
imagery ingestion, geospatial data persistence, and the versioned API that
the frontend and AI engine integrate against.

No application code has been added yet. Implementation begins in
**Phase 2 — Backend** of [`PROJECT_ROADMAP.md`](../PROJECT_ROADMAP.md).

For the intended architecture, domain model, and how this service
integrates with the AI engine and routing subsystem, see
[`docs/architecture/backend.md`](../docs/architecture/backend.md). The
resulting API surface will be documented in
[`docs/api/endpoints.md`](../docs/api/endpoints.md).
