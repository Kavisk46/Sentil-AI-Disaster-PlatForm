# SentinelAI Frontend

This directory will contain the React and TypeScript web application that
responders and incident commanders use to interact with SentinelAI: the
interactive map dashboard, damage overlays, routing views, and operational
briefing viewer.

No application code has been added yet. Implementation begins in
**Phase 3 — Frontend** of [`PROJECT_ROADMAP.md`](../PROJECT_ROADMAP.md).

For the intended architecture, component conventions, and how this service
integrates with the backend API, see
[`docs/architecture/frontend.md`](../docs/architecture/frontend.md).
