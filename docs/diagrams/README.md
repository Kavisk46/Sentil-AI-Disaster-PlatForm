# Diagrams

This directory holds source files and exported images for architecture and
flow diagrams referenced from `docs/`.

Where practical, prefer text-based diagram sources (e.g., Mermaid, embedded
directly in the relevant Markdown document, as used in the main
[`README.md`](../../README.md#system-architecture)) over binary image files,
so diagrams stay reviewable in pull requests. Use this directory for
diagram sources that require a dedicated design tool, and export a static
image into [`docs/images/`](../images/) for embedding.

No diagram source files have been added yet.
